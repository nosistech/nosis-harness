# Checklists

## New Project Checklist

- Copy template.
- Rename folder.
- Fill master context.
- Fill current task.
- Fill product brief.
- Fill roadmap.
- Fill architecture decisions.
- Start build log.

## Pre-Build Checklist

- Customer defined.
- First workflow defined.
- Current task defined.
- Risks listed.
- Tools/access known.
- Success criteria written.

## Pre-Release Checklist

- Tests pass.
- Security reviewed.
- Docs updated.
- Costs understood.
- Rollback plan exists.
