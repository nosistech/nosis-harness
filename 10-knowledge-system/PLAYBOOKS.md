# Playbooks

Repeatable workflows for the project.

## Playbook: Start A New Session

1. Read `00-start-here/MASTER_CONTEXT.md`.
2. Read `00-start-here/CURRENT_TASK.md`.
3. Read `00-start-here/BUILD_LOG.md`.
4. Confirm the next action.
5. Work.
6. Update `BUILD_LOG.md`.

## Playbook: Make A Decision

1. State the decision.
2. List options.
3. Compare tradeoffs.
4. Choose.
5. Record in `ARCHITECTURE_DECISIONS.md` or `DECISION_LOG.md`.
