# Quality Bar

## General

- Simple before clever.
- Secure before flashy.
- Useful before complete.
- Clear names before abstractions.
- Logs for important actions.

## Code

- Small modules.
- Tests around risky behavior.
- No hidden magic.
- No secret leakage.

## Product

- User can understand the workflow.
- Error states are visible.
- Outputs create real value.
